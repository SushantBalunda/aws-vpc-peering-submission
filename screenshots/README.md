# AWS VPC Peering — Evidence Checklist

Capture genuine screenshots from your AWS account.

- [ ] VPC A and VPC B with CIDR blocks
- [ ] Public and private subnets
- [ ] EC2 instances and private IP addresses
- [ ] Active VPC peering connection
- [ ] Route tables showing peering routes
- [ ] Security group inbound rules
- [ ] Successful App-A to App-B connectivity test
- [ ] Successful reverse connectivity test
- [ ] Controlled ICMP failure and recovery
- [ ] AWS resource cleanup after testing

**Security:** Hide account IDs and other sensitive information where appropriate. Never upload private keys, passwords, or access tokens.

**Status:** Evidence must be captured from the actual deployment. Do not mark items complete until verified.
